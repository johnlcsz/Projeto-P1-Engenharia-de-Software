## Descrição do projeto

O SEMAG é uma plataforma web desenvolvida para facilitar a descoberta e a avaliação de jogos digitais. O sistema permite que visitantes explorem um catálogo de jogos, pesquisem títulos e consultem informações detalhadas sobre cada um deles.

## Funcionalidades

- Cadastro de usuários
- Exploração do catálogo de jogos
- Pesquisa de jogos por nome
- Filtro de jogos por gênero
- Visualização de informações detalhadas de cada jogo
- Criação de avaliações
- Exibição do ranking de jogos mais populares com base nas avaliações da comunidade

## Como executar

1. Clone o repositório

```bash
git clone https://github.com/johnlcsz/Projeto-P1-Engenharia-de-Software
```

2. Entre na pasta

```bash
cd Projeto-P1-Engenharia-de-Software
```

3. Crie um ambiente virtual

Windows:

```bash
python -m venv .venv
```

Ative:

```bash
.venv\Scripts\activate
```

4. Instale as dependências

```bash
pip install -r requirements.txt
```

5. Execute o projeto

```bash
python run.py
```

6. Abra o navegador em

```
http://127.0.0.1:5000
```
